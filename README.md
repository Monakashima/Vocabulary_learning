# My Vocabulary v5.2 — Offline Test Mode

招待制・クラウド同期を維持しながら、
「単語テストだけはインターネット通信なし」で使える版です。

## 重要な動作

通常オンライン時:
- 招待ユーザー認証
- Supabase同期
- 辞書検索
- カード登録/編集
- 一括登録
- FSRS復習

オフライン時:
- 「復習」だけ利用可能
- 辞書APIへ通信しない
- Supabaseへ通信しない
- CDNへ通信しない
- 発音ボタンも非表示
- FSRS計算は事前保存したライブラリを利用
- Again / Hard / Good / Easy の結果は端末内に保存
- 再接続後、自動でクラウド同期

## 最初に1回だけ必要

オンライン・ログイン済みの状態で:

設定
→ アカウント / 同期
→ 「オフラインテストを準備」

を押してください。

これで:
- アプリHTML/JS
- アイコン
- service worker
- ts-fsrs 5.4.1

をブラウザのCache Storageへ保存します。

## オフラインテスト

準備後はWi-Fi/モバイル通信を切っても:

1. My Vocabularyを開く
2. 自動的に「復習」だけの画面になる
3. カードを回答
4. Again / Hard / Good / Easy
5. FSRS履歴をlocalStorageへ保存

という流れです。

## 招待制との両立

通信が完全にない状態では、
サーバー上で許可が取り消されたかを確認することは物理的にできません。

そのためv5.2では:
- 直近30日以内にオンラインで許可確認済み
- この端末で「オフラインテストを準備」済み
- この端末にカードが保存済み

の3条件がそろった場合だけオフライン復習を許可します。

30日を超えた場合は、一度オンライン認証が必要です。

オンラインへ戻ったら:
- approved_usersを再確認
- 許可取消ならアクセス停止
- 許可継続ならFSRS履歴を同期

します。

## 通信しないことを優先した設計

オフラインモードでは以下を表示しません:
- 高速登録
- 一括登録
- 一覧
- 設定
- 辞書検索
- 音声読み上げ

「復習」に必要なローカルデータだけを使います。

## 起動

ローカルPC:

    python3 start_local.py

GitHub Pages/PWA:
通常の公開URLを一度オンラインで開き、
「オフラインテストを準備」を実行してください。

## FSRS

オフライン用として `ts-fsrs 5.4.1` を固定してキャッシュします。
これにより `@latest` のCDNを毎回問い合わせません。

## データ同期

オフラインで行った復習結果は端末内に残ります。
ネット復帰後にSupabaseへ同期します。

複数端末を同時にオフラインで編集する使い方では競合が起こり得るため、
「オフライン中は復習のみ」に制限しています。
